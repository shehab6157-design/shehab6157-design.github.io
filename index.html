Flagship · public repoLateral-movement detection

APIS: Adaptive Protective Immune System

Detects attackers moving laterally inside a network. Like an immune system, it builds a per-device baseline of normal behavior across network traffic and Windows authentication, then flags what doesn't belong.

  • Four network signals: NEW_PEER OFF_HOURS VOLUME_OUTLIER FANOUT_SPIKE
  • Tested first on traffic I captured with tcpdump in a 3-VM lab, then on LANL's real public dataset
  • FastAPI REST API, SHA-256 hash-chained audit trail, baseline-poisoning drift monitor and an alert-flood countermeasure

MCP Proxy APIS, ported to AI agents 2026 · 8 phases
Tool calls · illustration

Public repoAI agent security

MCP Security Proxy: a behavioral firewall for AI agents

Sits between AI agents and their tools. Each agent gets least-privilege scopes, and the proxy learns its normal sequence of tool calls, so a hijacked agent stands out even when it uses legitimate credentials.

  • Scope enforcement, tool-call anomaly detection and baseline-drift detection for slow, evasive attackers
  • Scope-gated red-team engine and a purple-team orchestrator that scores each run
  • Live MITRE Caldera integration and a FastAPI web dashboard
